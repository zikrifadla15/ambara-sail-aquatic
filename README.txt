AMBARA SAIL AQUATIC — WEB APP
==============================

Versi awal aplikasi web responsif untuk Ambara Sail Aquatic.

File:
- index.html  = halaman utama
- style.css   = desain
- script.js   = fungsi menu dan pendaftaran WhatsApp

Cara mencoba:
1. Buka index.html di browser.
2. Klik "Daftar via WhatsApp" untuk menguji formulir.

Cara membuatnya online gratis:
- Upload tiga file ini ke GitHub, lalu aktifkan GitHub Pages; atau
- Import repository ke Vercel/Netlify dan deploy sebagai static site.

Catatan:
- Nomor WhatsApp pada aplikasi mengikuti nomor pendaftaran yang disediakan.
- Tautan Play Store masih berupa placeholder dan sebaiknya diganti dengan tautan aplikasi resmi saat tersedia.
- Data formulir versi ini tidak disimpan ke database; formulir langsung membuka WhatsApp.
